# TravelMate
TravelMate is a travel planning and trip management web application developed as a group project for Software Development 2.

TravelMate 
A web application for planning and managing trips.

1. Project Overview

TravelMate is a proposed web application designed to help users organise their trips in one place. Users will be able to create trip plans, view saved trips, update travel information, and delete trips that are no longer required.

This project is being developed as part of the Software Development 2 (CMP-L004-0) module at the University of Roehampton by the team Avengers Assemble.

2. Project Purpose

The purpose of TravelMate is to simplify trip planning by providing a central place to manage important travel information, including destinations, travel dates, estimated budgets, and notes.
The initial version will focus on implementing the core Create, Read, Update and Delete (CRUD) operations for trip management.

Project Objectives

Allow users to create and save trip plans.

Display a list of saved trips and their details.

Allow users to edit existing trip information.

Allow users to delete trips they no longer need.

Store and retrieve trip information using a MySQL database.

Develop a structured, maintainable web application.

3. Core Features

The planned initial features are:

Create: Add a trip with a title, destination, dates, budget, and notes.

Read: View saved trips and individual trip details.

Update: Edit existing trip information.

Delete: Remove a saved trip after confirmation.

Additional features may be considered as the project progresses.

The team is currently defining the project scope, documenting the core CRUD operations, preparing the project proposal, and organising tasks on the GitHub Project board.
